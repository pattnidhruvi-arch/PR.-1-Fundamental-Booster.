## 🎯 Objectives

- To learn the basics of Microsoft Excel.
- To create and format tables.
- To use Excel formulas for calculations.
- To organize data in a simple and clear way.

  ## 📂 Project Worksheets

My project contains three worksheets:

### 1. 🎓 Students Grade
This sheet contains student names, marks, total marks, percentage, and grades.

**Formulas Used:**
- Total: `=C2+D2`
- Percentage: `=E2/200*100`
- Average: `=AVERAGE(F2:F6)`
- Maximum: `=MAX(F2:F6)`
- Minimum: `=MIN(F2:F6)`

### 2. 💰 Sales Data
This sheet contains product names, quantities, unit prices, and total sales.

**Formulas Used:**
- Total Sales: `=C2*D2`
- Grand Total: `=SUM(E2:E6)`

### 3. 👩‍💼 Employee Data
This sheet contains employee IDs, employee names, departments, and salaries.

**Formulas Used:**
- Total Salary: `=SUM(D2:D6)`
- Average Salary: `=AVERAGE(D2:D6)`

  ## 🧮 Excel Functions Used

In this project, I used the following Excel functions:

- `SUM()` – To calculate the total.
- `AVERAGE()` – To calculate the average.
- `MAX()` – To find the highest value.
- `MIN()` – To find the lowest value.
- `IF()` – To calculate student grades.
- `INDEX()` and `MATCH()` – To find student names based on marks.
